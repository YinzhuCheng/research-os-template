# Asset Sources

Research OS Desktop does not ship static HTML documentation pages or a browser dashboard. Current visual assets are part of the Tauri/React application.

| Asset | Path | Source | License or constraint |
| --- | --- | --- | --- |
| Desktop app icons | `apps/research-os-desktop` | `lucide-react`; source references: `https://github.com/lucide-icons/lucide` and `https://lucide.dev/`, accessed 2026-06-07 | Lucide is licensed under ISC. Preserve this source record and license note if icons are copied or redistributed. |
| Tauri app icon | `apps/research-os-desktop/src-tauri/icons/icon.ico` | Locally generated Research OS package icon | Repository-owned package asset. Do not confuse with upstream Codex or OpenAI branding. |

## Maintenance Rules

- Record source URL, access date, license, and public-shareability when adding screenshots, external images, fonts, icons, third-party templates, or generated images.
- Do not place unsanitized private material, account screenshots, or raw experiment visuals containing private data in `PUBLIC/` or `docs/`.
