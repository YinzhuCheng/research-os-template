## 维护规则

- 新增截图、外部图片、字体、图标、第三方模板或生成图像时，必须记录来源 URL、访问日期、许可证和可公开性。
- 不把未脱敏的 PRIVATE 材料、原始实验图、含账号信息的截图放进 `PUBLIC/` 或 `docs/`。
