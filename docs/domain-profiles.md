# Domain Profiles

Research OS keeps domain-specific research judgment in domain profiles and skills rather than in a static HTML guide.

## Active Domain Routes

- Fundamental mathematics: `domain_profiles/fundamental-mathematics/` and `research-os-math-discovery`.
- Applied mathematics: `domain_profiles/applied-mathematics/` and `research-os-applied-math-modeling`.
- Machine learning: `domain_profiles/machine-learning/` and `research-os-ml-research-protocol`.
- Computer science: `domain_profiles/computer-science/` and `research-os-cs-research-artifact`.
- Statistics: `domain_profiles/statistics/` and `research-os-statistical-inference`.

## Governance

Domain skills run after `research-os-research-kernel` has a candidate and evaluator contract. They contribute field-specific artifacts, invariants, benchmark plans, proof obligations, diagnostics, and validity checks.

Validation is handled by:

- `scripts/check_domain_profiles.ps1`
- `scripts/check_agent_capabilities.ps1`
- `scripts/check_domain_templates.ps1`
- `scripts/check_domain_router.ps1`
- `scripts/check_domain_kernel_bindings.ps1`
