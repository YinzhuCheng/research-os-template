质量闸门

领域不可跳过的检查
基础数学定义范围、非平凡例子、反例搜索、lemma 依赖、proof-gap 和 human_checked。
应用数学应用问题、假设、单位/尺度、稳定性或误差路径、数值 sanity check、解释边界。
机器学习任务和指标、数据许可、baseline、leakage audit、ablation、seed/environment、cost-performance。
计算机科学接口和 workload、正确性义务、复杂度或性能范围、benchmark、artifact inventory、威胁模型。
统计学estimand、识别假设、抽样或功效、诊断、多重性和敏感性、不把不确定性压成二元显著性。

Harness 边界

所有领域 skill 都必须回到 `research-os-execution-harness`。无授权不得写 `PRIVATE/`，不得外部写回，不得使用付费资源，不得把未脱敏材料放进 `PUBLIC/`。数学 v1 不默认形式化证明，只保留 `formalization_future_slot`。
