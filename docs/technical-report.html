Research OS Desktop 技术路线

桌面应用是唯一主入口。React UI 通过 Python sidecar 治理 `.rosproj` 项目、权限、归档和可选 Codex runtime。

核心边界

层职责
React UI项目中心、三阶段工作台、选择控件、审批、存档和最终产物弹窗。
Python sidecar项目文件、状态、沙箱路径、profile、approval、archive、runtime events。
Codex runtime可选执行内核；所有命令与权限请求必须经过 sidecar 审批。

Process Contract

机器可读流程在 config/research_flow.yaml。用户视角仍是 initialization、research loop、final product 三阶段。

Final Product Tracks 支持 paper、research report 和 software 多选；导出、发布和外部写回都需要人工确认。

Git-Backed Archives 用于长任务前、阶段切换前和风险操作前的本地 snapshot。
