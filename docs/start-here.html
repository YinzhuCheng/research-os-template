Start Research OS From Material

You do not need to answer a long setup questionnaire. Open the copilot page, describe the direction or upload material, then Codex asks only three targeted questions before initialization.

First Step

Open the cockpit

Use PUBLIC/copilot.html as the first screen.

Add material

Upload a research plan, notes, ChatGPT conversation export, PDF, zip, or demo. A short text direction is also enough.

Let Codex profile it

Codex classifies the project as theory, experiment, theory+experiment, engineering system, survey, or unclear.

Only Three Targeted Questions

Questions are generated from the material. Each has a recommended answer, options, and an Other/free-form answer path.

What Initialization Produces

  • Research motivation and expected goals.
  • Contribution claims.
  • Related research, shortcomings, and how this research relates to it.
  • Reference links and a lawful download script.
  • Theory framework and candidate theorems when the project is theory-heavy.
  • Experiment plan and minimum validation when the project has experiments.
  • Repository links to work order, phase gate, schemas, templates, manifest, and ledger.
