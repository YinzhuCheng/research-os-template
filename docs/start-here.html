Research OS Desktop 快速开始

从桌面应用创建或打开 .rosproj 项目。项目同名目录是沙箱，Research OS 在其中治理材料、状态、Codex 执行、归档和最终产物。

第一步

  1. 阅读 Desktop App 指南。
  2. 创建 `.rosproj` 项目并输入研究材料。
  3. 回答 exactly three targeted questions。
  4. 进入半自动循环：验收、对齐、执行、分析。
  5. 需要论文、报告或软件时，从最终产物弹窗进入第三阶段。

安全边界

原始材料默认进入项目内 PRIVATE/。公开状态只写入 PUBLIC/research_state.json。凭据只允许使用环境变量或系统凭据引用。
