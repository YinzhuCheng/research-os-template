# Submission Checklist

- [ ] Target venue template is used.
- [ ] Anonymous submission settings are correct.
- [ ] Every major claim appears in `claim_evidence_matrix.yaml`.
- [ ] Figures are vector where possible.
- [ ] Tables use `booktabs` and aligned numbers.
- [ ] Appendix includes reproducibility details.
- [ ] References compile and contain no fabricated entries.
- [ ] AIGC images, if any, have provenance and human approval.
