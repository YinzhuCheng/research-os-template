# Analysis Rules

- Report exact metric definitions before interpreting numbers.
- Compare against the researcher-confirmed criterion, baseline, control, prior observation, theoretical target, or expert rubric as applicable.
- Report resource use against `resource_budget`.
- Distinguish statistical noise from systematic failure.
- Link every conclusion to `RES-*`, `RUN-*`, or `EXP-*`.
- Record missing tests as limitations, not as implicit success.
