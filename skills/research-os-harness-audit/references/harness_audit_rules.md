# Harness Audit Rules

- `AGENTS.md` is durable project guidance; it must stay concise and enforceable.
- `.codex/config.toml.example` is a template until the researcher opts in.
- Sandbox and approval define technical boundaries; hooks add policy checks.
- Any MCP server must declare data boundary, rate limit, cost risk, and allowed tools.
- Audit failures should block public export and real resource calls until resolved.
