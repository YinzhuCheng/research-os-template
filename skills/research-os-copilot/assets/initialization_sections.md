# Initialization Sections

- Overview: motivation, goals, contribution claims, current research type.
- Literature: related work, shortcomings, relationship to this research, reference links.
- Theory: framework, definitions, candidate theorems, proof or validation notes.
- Experiment: plan, required budget, metrics, stopping rules, minimum validation.
- Repository Links: work order, phase gate, schemas, templates, manifest, ledger, domain profiles, kernel artifacts.
