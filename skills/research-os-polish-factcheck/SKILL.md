# Research OS Polish Factcheck

Use this skill after a manuscript draft exists.

## Workflow

1. Read manuscript, claim-evidence matrix, references, and target venue expectations.
2. Diagnose before rewriting:
   - logic gaps,
   - unsupported claims,
   - overclaiming,
   - section order problems,
   - vague or template-like sentences,
   - factual risks.
3. Produce patch-style suggestions or apply edits if the user requested apply mode.
4. For factual claims, mark: supported, partially supported, unsupported, unverifiable, or outdated.
5. Preserve technical precision over cosmetic smoothness.

## Quick Checks

- Read `references/polish_factcheck_rules.md` before editing manuscript prose.
- Do not promise to bypass AI detectors.
