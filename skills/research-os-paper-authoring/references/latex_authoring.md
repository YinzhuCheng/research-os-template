# LaTeX Authoring Rules

- Use target venue class when available; otherwise use the neutral template.
- Keep source modular: main text, appendix, figures, tables, references.
- Use `booktabs`, `siunitx`, `xcolor`, `tikz`, and `pgfplots` for polished technical presentation.
- Every figure caption should state the takeaway.
- Appendix should contain enough detail to reproduce results.
- Anonymous submissions must avoid author-identifying paths, acknowledgements, and links.
