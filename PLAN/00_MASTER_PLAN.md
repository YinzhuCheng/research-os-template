# Research OS Desktop Master Plan

## Objective

Build Research OS Desktop as a governed local researcher-copilot app. The product converts research conversations, draft plans, notes, links, and demos into auditable `.rosproj` projects with a sibling sandbox directory.

## Defaults

- Product route: Tauri + React + Python sidecar.
- Runtime route: optional official Codex SDK/app-server, mediated by Research OS approval policy.
- UI language: Chinese by default.
- Repository documentation language: English.
- Privacy: strict `PUBLIC/` and `PRIVATE/` separation.
- Resources: budgets are researcher-defined and must cover time, compute, cloud, API/model calls, human work, instruments, and other real resources.
- Final products: paper, report, and software are optional tracks selected by the researcher.

## Core Outputs

- Desktop app and Python sidecar.
- `.rosproj` project model and seed structure.
- Multi-level skill suite.
- Research object schemas and artifact templates.
- Codex harness files, audit controls, privacy scan, resource guard, and export scripts.
- Optional LaTeX paper, visual communication, polish, fact-checking, and review/rebuttal routes.

## Non-Goals

- No automatic submission.
- No automatic external platform upload.
- No default model, provider, dataset, baseline, budget amount, or experiment paradigm.
- No promise to evade AI detectors; polish means reducing boilerplate, vague claims, and unnatural structure.
