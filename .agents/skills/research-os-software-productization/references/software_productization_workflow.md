# Software Productization Workflow

The software track prioritizes practical usefulness and user experience while preserving research provenance.

## Default Product Standard

- clear user workflow;
- stable inputs and outputs;
- graceful errors;
- responsive and accessible UI if frontend is involved;
- concise documentation;
- meaningful tests or validation scripts;
- preserved intermediate artifacts.

## Free-form Target Adjustment

The researcher can override scope in natural language, for example: "make it a demo only", "prioritize CLI stability", "ship a web app", or "focus on internal reproducibility over polish".
