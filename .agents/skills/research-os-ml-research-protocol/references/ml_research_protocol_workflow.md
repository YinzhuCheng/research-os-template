# ML Research Protocol Workflow

Subfield routes:

- classical ML: feature construction, simple baselines, calibration, robustness, and interpretability.
- reinforcement learning: environment spec, reward design, off-policy risk, seeds, and stochastic evaluation.
- transfer learning: source/target gap, adaptation protocol, negative transfer, and few-shot split.
- computational learning theory: assumptions, sample complexity, proof obligations, and counterexamples.
- computer vision: dataset leakage, augmentation policy, annotation quality, and visual failure modes.
- NLP: data contamination, prompt leakage, multilingual coverage, and annotation guidelines.
- generative AI: evaluation validity, safety limitations, cost, model provenance, and misuse risk.

Acceptance rule: a public ML result requires task card, data card, baseline matrix, leakage audit, ablation plan, evaluation harness, and reproducibility notes.
