# Resource Guard Rules

- Budget values come from the researcher or an explicit decision record.
- Treat unknown cost as a risk, not zero.
- Real resources include money, cloud quota, API quota, model calls, lab supplies, instrument time, participant incentives, annotation labor, and external services.
- Use hard stops for budget overruns and external writeback.
- Record estimates separately from settled costs.
- If provider billing has delayed settlement, mark residual risk in the ledger.
