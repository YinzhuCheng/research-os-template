# Report Authoring Workflow

Research reports are allowed to be more detailed than papers. They should preserve the reasoning path, intermediate data, failed attempts, and audit trail.

## Default Structure

1. Executive summary
2. Source material and boundaries
3. Research questions and accepted decisions
4. Methods, probes, and execution notes
5. Results, including negative and inconclusive findings
6. Evidence table
7. Reproducibility package
8. Limitations and next actions

HTML is the default readable output. LaTeX/PDF and PPT are generated only when selected in the final product plan.
