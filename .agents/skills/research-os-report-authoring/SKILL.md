# Research OS Report Authoring

Use this skill when the final product track includes a research report.

## Workflow

1. Read the `final_product_plan`, accepted analysis reports, claim-evidence matrix, run manifests, resource ledger, and figure plan.
2. Confirm report expectations using a choice prompt with recommended option, options, and free-form natural-language input.
3. Draft a report structure that emphasizes source material, research process, initial data or assumptions, successful and failed results, reproducibility notes, evidence links, limitations, and next decisions.
4. Produce selected output formats: HTML, LaTeX/PDF, or PPT.
5. Use `research-os-visual-communication` for figures and tables, and `research-os-polish-factcheck` for prose/evidence cleanup.
6. Preserve all intermediate outputs and validation reports.

## Boundaries

- Do not overclaim novelty when the evidence only supports a process report.
- Do not invent data, citations, or results.
- Do not expose private raw material in public reports.
