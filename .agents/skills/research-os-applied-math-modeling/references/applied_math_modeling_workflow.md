# Applied Math Modeling Workflow

Default loop:

1. Translate the application question into variables, objectives, and constraints.
2. Record assumptions and missing mechanisms before solving.
3. Check units, scales, and nondimensional groups.
4. Identify stability, well-posedness, approximation, or numerical error obligations.
5. Design minimal validation and sensitivity probes.
6. Interpret results with explicit regime and application limits.

Acceptance rule: a model result requires assumptions, scale/regime checks, stability or error reasoning, and sensitivity limits.
