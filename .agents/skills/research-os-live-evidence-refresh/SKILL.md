# Research OS Live Evidence Refresh

Use this skill whenever a research decision depends on current external information.

## Workflow

1. Identify time-sensitive claims and decisions.
2. Search current sources using the narrowest reliable source set:
   - official documentation for tools, APIs, pricing, and rules,
   - paper pages or publisher pages for literature,
   - venue pages for deadlines and formatting,
   - dataset/license pages for data use,
   - regulatory or ethics sources for compliance.
3. Record source URL, access date, source type, freshness risk, and affected research objects.
4. Update claim status if evidence is contradicted, outdated, or unverifiable.
5. If network access is unavailable, mark the affected item as high freshness risk.

## Quick Checks

- Read `references/live_evidence_rules.md` before writing snapshots.
- Do not cite memory for current prices, deadlines, rules, APIs, or recent literature.
- Keep raw private source material out of public snapshots.
