# Visual Rules

- Prefer colorblind-safe palettes.
- Avoid low-resolution PNG as final data figures.
- Use consistent typography across figures and tables.
- Use `booktabs` for tables and `siunitx` for aligned numbers.
- Make captions conclusion-oriented.
- Keep appendix figures visually consistent with main figures.
- If using AIGC, record provenance and require human approval before submission.
