# Documentation Site Rules

- The quick-start page should answer what the repository is, who controls the research, what to do first, and where to click next.
- The technical report should answer how the repository is wired, what state files matter, how skills route work, how integrations map outputs, and how validation is run.
- Every durable HTML page must link back to `README.md`, `CONTROL/work_order.yaml`, `CONTROL/phase_gate.yaml`, `PUBLIC/index.html`, and at least one provenance artifact.
- Prefer stable repository-relative links over absolute local paths.
